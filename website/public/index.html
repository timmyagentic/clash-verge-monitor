KNOW BEFORE YOU START

把边界，
也说清楚。

使用前了解版本、兼容范围与数据含义。
有具体问题，欢迎在 GitHub 提交反馈。

能还原安装前的流量吗？

不能。它从采样开始记录未来的连接字节增量，无法从缺少字节计数的旧日志中还原精确历史。

unknown 是否说明有可疑流量？

不一定。unknown 首先表示进程归因的覆盖缺口；高用量或周期性连接也不是恶意软件结论，需要结合时间、目标与上下文核对。

会改动代理规则或上传账本吗？

采样与审计面向控制器读取和本地 SQLite，不负责修改路由规则。内置 Web 页面只读且面向本地，网站也不会连接你的控制器或读取账本。

清理历史会保留哪些数据？

维护命令默认先预览。明确应用清理后，旧原始明细可能无法再下钻；每日汇总按命令约定保留。执行前应阅读相应版本的保留和备份说明。
