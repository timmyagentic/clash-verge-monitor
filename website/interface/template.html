MADE FOR EVERYDAY USE

不只看数字，还看它从哪来。

记录、归因、覆盖和证据一起看，才能知道一个用量结论有多可靠。

01

把瞬时流量，留下来。

按连接采样字节增量，保存原始明细与每日汇总。已有连接建立基线，避免把启动之前的流量算进来。

02

应用与目标，一起核对。

优先使用 Mihomo 进程元数据，必要时结合本机可见套接字归因。无法确定的来源标为 unknown，并报告覆盖缺口。

03

让 Agent 回答得有依据。

通过 CLI 和随项目提供的 Skill 查询健康、用量、审计与证据。审计使用只读访问，数据维护默认先预览。
